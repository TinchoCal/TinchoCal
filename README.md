## 🚀 Proyecto destacado

### ⚽ Gestor de Turnos — Complejos Deportivos

Aplicación web desarrollada como **Proyecto Final de la Tecnicatura Universitaria en Programación**, orientada a la gestión de complejos deportivos, canchas y reservas.

El proyecto fue desarrollado junto a **Tobías Escoca** y cuenta con una arquitectura backend basada en **.NET y C#**, siguiendo el enfoque de **Clean Architecture**.

**Principales funcionalidades:**

* 👤 Gestión de usuarios y diferentes roles
* 🏟️ Administración de complejos deportivos
* ⚽ Gestión de canchas
* 📅 Gestión y reserva de turnos
* 🔔 Sistema de notificaciones
* 🔐 Autenticación y autorización mediante JWT
* 🔄 Operaciones CRUD
* 📚 Documentación de la API mediante Swagger
* 🌤️ Integración con una API externa para consultar el clima
* 🚀 Implementación de CI/CD mediante GitHub Actions y Azure

**Tecnologías principales:**

`C#` `ASP.NET Core` `.NET 10` `Entity Framework Core` `SQLite` `JWT` `Swagger` `GitHub Actions` `Azure`

**Arquitectura:**

`Clean Architecture` — `Domain` · `Application` · `Infrastructure` · `Web API`
